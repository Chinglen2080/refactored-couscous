# refactored-couscous

1. Install Python and Required PackagesMake sure Python 3 is installed on your Ubuntu or Termux environment.Install the pyserial package which the script uses for serial communication:pip install pyserial2. Connect Your HardwareFor wired mode, connect your Arduino to your computer via USB.For wireless mode, set up a wireless receiver (e.g., another Arduino with nRF24L01) that forwards received data through serial/USB to your computer or phone.3. Find the Correct Serial PortOn Ubuntu, typical serial port names are /dev/ttyUSB0, /dev/ttyACM0, etc.On Termux, USB serial ports might be accessed via extra steps (termux-usb or permissions).On Windows, it might be COM3, COM4, etc.You can list ports using:ls /dev/tty*on Linux or check Device Manager on Windows.4. Run the ScriptExecute the script in a terminal or Termux shell:python3 your_script_name.pyWhen prompted:Enter connection mode: wired or wirelessEnter the serial port corresponding to your hardware connection.The script will start logging and printing data.5. Optional - Arduino SideEnsure your Arduino is running the matching sketch:For wired mode, the original sketch with serial outputs.For wireless mode, the sensor Arduino transmits data wirelessly and a receiver Arduino forwards it to the serial port.
